アイテム合成 Crafting

出典: Grimoire : Heralds of the Winged Exemplar Wiki
Grimoire ファン Wiki の記事「Crafting」の日本語訳です。原文は 2019 年ごろの版（V2）について書かれていて、今の版（3.0）とは違うところがあるかもしれません。

合成の画面に入るには、キャラクターの肖像を右クリックして「持ち物工房」を選ぶ。

どんな組み合わせを狙うかによって、毒術（武器に毒を塗る）か錬金術の技能を持つキャラクターが要る。錬金術は奇跡術師にとっては呪文を唱えるための技能も兼ねている。毒術も錬金術も精神技能で、いくつもの職業が持っている。

合成のアイコンは、「合成」のボタン以外は、それに合った作業場（crafting station）でしか出てこない。「鍛造」が出るのは鍛冶場だけ。「研ぐ」と「毒を塗る」が出るのは炉辺だけ。武器への付与も同じで、祠でしか出ない。ふつうの冒険の画面では「合成」のボタンしか使えない。

場所が合っていると、一部の技能の効き目が大きく上がる。鍛冶場で作業しているときは、冶金術が実質2倍になる。毒術（毒）と短剣術（武器を研ぐ）にも同じような効果がある。

合成で組み合わせられるアイテムの例:

毒術:

針投矢 + 毒の粉 = 毒投矢

左手剣 + 毒の粉 = 毒の短剣

毒の粉 + 狩猟ナイフ = 毒の短剣

毒の粉 + 返しの矢 = 毒矢

錬金術:

軽傷治癒 + 軽異常治癒 = 重傷治癒

ネマチック粉 + マンドレイクの根 = 麻痺の粉

巡礼者の茶 + レテの酒 = 石化解除

さくらんぼ酒 + レテの酒 = 深紅の神酒

レテの酒 + 軽異常治癒 = 麻痺治癒

重傷治癒 + さくらんぼ酒 = 解毒

重傷治癒 + ヒ素 = 麻痺治癒

重傷治癒 + アマランス = 石化解除

重傷治癒 + ベラドンナ = 解呪

煮え油 + 竜の胆汁 = 超煮え油

煮え油 + 悪臭弾 = 超煮え油

煮え油 + 中性の媒剤 = 真実の目

煮え油 + 軽異常治癒 = 解毒

麻痺の粉 + 毒の粉 = メデューサの粉

麻痺の粉 + 毒人参 = 毒蛇の灰

人馬殺し草 + 竜血樹の花弁 = 解呪

ゼファーコーラ + 軽異常治癒 = 石化解除

ゼファーコーラ + アマランス = 麻痺治癒

ゼファーコーラ + 黒い蓮 = 解毒

ゼファーコーラ + 煮え油 = 超煮え油

吉草根 + 大天使草 = 火花の袋

吉草根 + 血のタマリンド = 解毒

吉草根 + 苦い芋 = 麻痺治癒

吉草根 + 黒薔薇 = 重傷治癒

竜血樹の花弁 + ヒ素 = 毒の粉

癒し草 + アマランス = 眠りの袋

癒し草 + 軽傷治癒 = 重傷治癒

癒し草 + 軽異常治癒 = 麻痺治癒

黒い蓮 + ヒ素 = 毒の粉

ハーピーの冠 + 血のタマリンド = 転移

ヒ素 + 墓場の苔 = トリカブト

ヒ素 + 棺桶蘭 = 眠りの砂

白腐れ草 + 斑入り大葉子 = 悪臭弾

霊精の小瓶 + 夜霧の小瓶 = 前物質エクトプラズム

夜霧の小瓶 + 荘厳の笛 = 前物質エクトプラズム

注意

覚えておくこと: 上の組み合わせは「主材料（primary）+ 副材料（secondary）」の順に書いてあり、この順番には意味がある。台に置く順番はどうでもいいが、合成や毒塗りをするときは主材料のほうを選ばなければならない。

台の上のアイテムをクリックすると、それを調合するのに必要な技能と、その技能のレベルが表示される。これまでに見たのは錬金術か毒術のどちらかだった（錬金術のほうがずっと多い）。本草学や冶金術が必要なアイテムはまだ見つけていないが、冶金術のほうはきっとあると思っている。クリーヴの話では、冶金術の表の多くは欠けているが、全部ではないそうだ。

アイテムをクリックして「不明」と出ても、そのアイテムが何とも組み合わせられないとは限らないので注意。どのレシピでも「主材料」にはならないが、「副材料」にはなる、という意味のこともある。たとえば台の上の軽異常治癒の薬をクリックすると「不明」と出る。だが、これは煮え油や軽傷治癒と調合するときの副材料になる。

アイテムを組み合わせると、まとまった数ができることがある（毒の粉1つ + 返しの矢1本で、毒矢が20本以上できることもある）。
