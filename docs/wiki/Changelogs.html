Grimoire V2.0 で追加された内容

新しい場所: 滅びの墓所（祠、鍛冶、託宣者）。ハラダンの木立の地図にある。

新しい場所: ギデオンの生垣迷路の中の神智学会館（銀の守護像が手に入り、これを使うと各地の祠でレベルアップを買える。会館に入るには、滅びの墓所で手に入る小像と合言葉が要る）

新しい場所: 鴉の荒野の邪悪な場所（Evil Place）（死者の要塞の下、ネクロポリクスで見つかる合言葉が要る）

新しい場所: バホメットの荒野の沼地の小屋（錬金台がある）

新しい場所: ネルクザンの森のタトルテイル・サーカス（ミニゲームで遊べるラットゥのカジノ。入るにはラジ・カーンから合言葉を聞き出す）

新しい場所: ネルクザンの森の裂け目（ボス戦と、タトルテイル・サーカスに関わるクエストがある）

新しい場所: 蔓日々草山（登攀の難度は 9/10）。エグゼンプラー大領国の地図から行ける。

  • 蔓日々草村
  • 蔓日々草の研究所（Periwinkle Laboratory）。祭壇の書がある
  • 蔓日々草の厨房（炉辺、ACME の自販機）
  • 蔓日々草の礼拝堂（祠、CON +1 と WIS +3 の泉）
  • 蔓日々草の鍛冶屋（炉辺、鍛冶）
  • タイタンの地底湖
  • タイタン鉱山
  • 蔓日々草の宿
  • 世界の果ての小屋
  • 大災厄（位相プラズマ銃と電池）
  • 新しいエンディング（任意。時計を二度使って未来へ進む）

新しい仕組み: 気力ゲージ（Spirit Bar、SPI）。邪悪な魔物に出会うと減ることがあり、尽きると恐怖に陥る。DEV（信仰心）が高いキャラクターほど屈しにくい。気力ゲージを回復させるには、祝福、心の盾、奇跡のどれかを唱える。起動した祠や、安全地帯の一部の場所で休んでも回復する。

バージョン 1.2.0.25

公開日: 2017年8月18日

  • 骨の短剣（と、同様のアイテムすべて）に上級鑑定を使ったときの不具合を修正
  • アニメーションのハンドルの妥当性を調べる assert を削除（ネクロポリクスで像を回すと落ちていた）
  • さまよう魔物の出現間隔の判定を調整
  • 戦闘で投げたアイテムの回収処理（Chucker collection）を修正
  • 多くの NPC が、初めて会ったあと AutoActive になるようにした（その後も確実に会えるように）
  • 地下の獣舎のクォールの泉の不具合を修正（CGX キーの設定が間違っていた）
  • スナークの下段寝台で一部の部屋をふさいでいた本棚を撤去
  • 枢軸監獄の牢の鍵の使用回数を一回増やし、枢軸監獄の門をすべて開けられるようにした
  • 名前のないキャラクターで書庫が落ちる不具合
  • 凪の竪琴が「急速冷凍」ではなく「冷気円錐」を放つようにした
  • 戦闘中、対象を味方から魔物に切り替えたときの呪文の再指定

黒きリッチ戦で退却するとおかしくなるという、一人のユーザーから報告のあった不具合は、まだ再現を試みているところ……

ほかにも、ユーザーの要望を受けてアイテム・魔物・NPC の細かい修正を多数。

修正の大半は、ゲームの進行を直接妨げる問題への対処で、バランス調整はまだ。

画面まわりの修正。

バージョン 1.2.0.21

公開日: 2017年8月13日

クロウルの小さな建物で、いくつかの錠が働いていなかった。5 つほどの錠が間違ったリンク番号を使っていて、扉を回して通れる状態にできなかったのだ。ヴァンガード士官宿舎（Vanguard Officer's Quarters）や金庫など、重要な建物にあるメインクエストの錠はすべて試し、ゲームの流れのうえで正しく動くことを確かめた。

修正し、テスト済み。


バージョン 1.2.0.20

公開日: 2017年8月13日

別の場所を面白くしようと赤いモザイクの床板を「NO SLEEP」（眠れない）に設定したところ、クノッソスの塔に不具合が出た。信じがたいことに、この床板はクノッソスの塔のモノリスの真下にあった。頂上へ進むには、まさにそのモノリスのところで眠らなければならないのに。このあたりのデータは互いの絡みがあまりに多く、ほんの小さな変更一つで大がかりなドミノ倒しが起きてしまう。

申し訳ない。もう直してある。梯子を登ってノルロス・クノッソスと戦えるはずだ。このせいでギデオンで足止めされていた人も、これでこの地域を終えられるはずだ。


バージョン 1.2.0.19

公開日: 2017年8月13日

セーブデータから再開すると、十年ほど前にバホメットの第3のとぐろに仕込んだ一連の床ポインタが 0 になってしまう。結局実装されなかった機能を見越して入れていたものだ。これでバホメットの頂上へはまったく進めなくなっていた。とんでもない不具合だ。

もともとは、これらの床の下にアニメーションで瞬く光を置き、暗闇の中で引き鎖から引き鎖へと導いて、次に何をすれば先へ進めるかをそれとなく示すつもりだった。それが実装されないまま、床ポインタは届くことのなかったアニメーションの画像を待って 0 のまま残っていた。

この床ポインタを入れたのは 1999 年ごろだったと思う。それ以来一度も触らず、何の害もなさそうにそこに置かれていた。

ともかくもう直してある。申し訳ない。どのセーブデータからでも、今のゲームの状態からでも先へ進めるはずだ。これらの引き鎖の下には、落とし穴ではなく床があるようになった。


バージョン 1.2.0.18

スカルハイムのゲーム進行の不具合を直す緊急修正。

条件によっては、スカルハイムの北東の隅にある落とし穴を閉じたあと、また開いた状態に切り替えられてしまった。こうなるとオルロック伯爵の隠れ家にたどり着けない。落とし穴の横の壁にあるボタンは、押しても何も起きないようにした。ゲームのポインタは何も変えていないので、閉じたあとの落とし穴がまた開かないようにする以外の影響はないはずだ。

すまない、これは最終確認のときに自分でも頭を抱えた箇所だった。落とし穴をどこから閉じる作りにしたのか忘れてしまい、結局その横にボタンを置くという力ずくのやり方にした。これなら間違いないと思ったのだ。ところがこのボタンで落とし穴をまた開けられてしまい、そうなると通れなくなって、渡ろうとするたびに下の階へ落とされる。ゲームのクリアが妨げられるわけではないが、スカルハイムのかなりの部分が切り離されて行けなくなる。直ったはずだが、ほかに問題があれば知らせてほしい。すぐに調べる。


バージョン 1.2.0.17

イベントスタックの動き方を少し変えたせいで、ノック・ノックという NPC 一人の処理が壊れていた。彼は自分の森にいる「あのムカつく蜂ども」を退治してほしいと頼んでくるのだが、クエストを終えて彼のところへ戻っても報酬がもらえなかった。この処理を直したので、すでにこのクエストを終えている人も、ノック・ノックのところへ行けば報酬を受け取れる。

致命的な不具合でも大きな修正でもないが、この地域ならではの楽しい体験が戻ってくる。ノック・ノックは、これらの地図を歩き回っていると出会う大勢の変わった連中の一人だ。敵意をむき出しにしてくる者もいるが、あの木のように友好的な者も多い。


バージョン 1.2.0.16

大きな不具合の大きな修正！魔物からごくまれに手に入る「運試しの鍵」の問題は、これですべて解決するはずだ！ ほかにも、原因のよくわからなかったクラッシュがいくつか直るはずだ。

この問題をじっくり調べて直した。ひと月前、宝の組み合わせのデータベースを移すのに使うユーティリティを再コンパイルするため、Windows 7 のマシンに Borland C++ コンパイラ 5.0 を入れた。そのときは知らなかったのだが、インストーラに不具合があり、構造体のアラインメントを 4 ワード境界と決めつけて、1 バイト詰めのアラインメントにするコンパイラのスイッチを上書きしていた。 そのユーティリティを走らせると、ひどい代物ができあがった。しかも信じがたいことに、それがたいていはちゃんと動いてしまい、 壊れていることが隠れていた。そのデータは、壊れたバイナリのまま、いつ問題を起こしてもおかしくない状態で置かれていた。

そのファイルを掃除して書き出し直す新しいユーティリティを書いた。このファイルは 20 年前のもので、 最初に書き出したのは、大昔の MS VC 1.0 コンパイラで自作した Windows 3.1 のエディタだった。 今ではまた、まっさらできれいなバイナリデータに戻っている。

本当の assert を引き起こす類の不具合は、これが最後のほうになるはずだ。今日調べたほかの問題は、どれも決まって、1.2.0.7 のころのセーブデータをまだ使おうとしているか、同じビルドの壊れたデータで設定ファイルがおかしくなっているかだった。

これで、ゲームがだんだん安定していく新しい時代が始まればと願っている。誰かが YouTube に上げた 14 時間のプレイ動画を飛ばし飛ばし見てみたが、不具合には一度も出くわしていなかった。一週間後にはそれが当たり前になっていてほしい。

バージョン 1.2.0.12

よし、これらの問題は片づいたようだ。いつものように、大事なファイルをよそにコピーしてからアンインストールし、更新した新しい版を入れ直せば、問題は解決する

ユーザーのアプリデータのフォルダを作る要求はコメントアウトしたのだが、権限トークンを取る呼び出しをコメントアウトし忘れていた。そのため、場合によっては既存のファイルを上書きする権限のないセキュリティトークンが開いたままになっていた。これは直した。

マニュアルを書いているあいだ、この版が数日だけでもおとなしく安定して、ちゃんと動いてくれることを心から祈っている。一行の名前の付け方など、基本的な操作やゲーム開始まわりの要望を受けた修正が、この更新にはたくさん入っている。いずれゲームのメニューに「RENAME PART」（一行の名前を変える）機能も入ると思う。


バージョン 1.2.0.9

ちょっとした危機は回避できた。たぶん。キャッシュを消し、ゲームが確実にアンインストールされていて、 フォルダにファイルが残っていないことを確かめてほしい。セーブデータは必ずよそにコピーしておくこと。

ゲームを入れたら、RPG100.lib とセーブデータのファイルを元に戻す。読み込めないなどの問題があれば知らせてほしい。自分で作るまでは、当面このビルドに入っている「fast.qst」ファイルを使ってほしい。

Steam 版の側でユーザーのアプリフォルダを作る権限をどう得るかがわかるまで、ユーザーデータはメインのフォルダに置いておくしかない。自動更新をオンにしたので、ユーザーデータを失わずに .exe と .rsf だけを更新できるようになった。データが消えるのはアンインストールしたときだけだ。念のため、たまにこのファイルをバックアップしておくといいかもしれない。

このビルドでまた全部ちゃんと動くようになったと聞きたい。手元のノートパソコン二台で試したところ、問題なく動くようだった。上に書いたとおり、古い壊れたファイルをそのディレクトリに残さないこと。以前のセーブデータは、1.2.0.5 かそれより前に作ったものなら読み込めるはずだ。バージョン番号は exe に組み込まれ、リリースのたびのコンパイルで自動的に付くようになったので、画面に出る番号はいつもログに書かれる番号と一致するはずだ。

すべてがおおむね元どおりになったと聞きたい。今公開中の版を使っているか確かめるため、バージョンが「1.2.0.9」になっていることを確認してほしい。


バージョン 1.2.0.8

この版で、1.2.0.5 以前の既存のセーブデータは直るはずだ。残念ながら、それより後の版のセーブデータはすべて壊れてしまう。本当に申し訳ない。今後は、どのセーブデータにも保存したときのバージョン番号が書き込まれる。セーブデータがあれば安全な場所にコピーしてから、GRIMOIRE のユーザーアプリデータのフォルダ（たいていは「C:\Users\user\AppData\Local\GRIMOIRE」）を探し、そこにセーブデータのファイルをコピーしてほしい。そうすれば次にゲームを起動したとき読み込めるようになる。作ったキャラクターを残しておきたいなら、RPG100.LIB も同じようにしておくといいかもしれない。

セーブデータ、クイックスタートのファイル、キャラクターの入った RPG100.LIB は、設定ファイルと一緒に Windows のユーザーアプリデータのフォルダへ移す。これで、自動更新でセーブデータが上書きされずに済む。これでずっと先へ進みやすい形になった。

持ち物のページ送りを加え、持ち物を一画面ぶんずつ飛ばせるようにした。ここ数週間で何度も寄せられた不満への対応だ。

このビルドにはほかにも不具合の修正が入っている。安定して、今のプレイヤーが全員更新し終えたら、今後のすべての更新で不具合の修正を詳しく記録するつもりだ。自動更新をオンにしておけば、ゲームエンジンの絶え間ない改良が、そのうち気づかないほどすんなり届くようになると思う。

フルスクリーンでのウィンドウの拡大縮小が、一部のモニターでまだ壊れたままなのは残念だ。ただ、10 人中 8 人はこのモードで問題なく遊べているので、オプションは消さなかった。この問題は調べて、きっちり解決するつもりだ。それまでのあいだ、Grimoire をフルスクリーンで正しい比率のまま画面いっぱいに表示する別の方法を、フォーラムで多くのユーザーが教えてくれている。それが大事なら、当面はそうした方法を試してみてほしい。

設定ファイルのせいで画面が真っ暗になったり落ちたりしたら、上のユーザーアプリケーションのフォルダから消すとよい。次にゲームを起動したとき、標準の設定ファイルが作られる。


バージョン 1.2.0.7

当初の更新履歴

持ち物の欄の左右に、ページ送りを加えた。とても大勢の人にとって大事な機能だ。今はゲームの進行を妨げる致命的な不具合をなくすことに専念しているところだが、UI を使いやすく、素早くスクロールできるようにしてほしいと何度も頼まれていたので、これは入れた。

アクアヴィアで Rezpack の assert が出る不具合が直ったかどうかも、ぜひ聞かせてほしい。実のところ、わたしにとって何より大事なのは、ゲームが止まる不具合をなくし続けることだ。細かい調整や小さな不具合は後でも直せる。

不具合を見つけたら、再現の仕方を説明してもらえれば必ず直すことを覚えておいてほしい。

この更新で新しい問題が出ていないか確かめるため、このスレッドのロックを外して意見を受け付ける。ここで投稿を消すことがあっても、それは意見を書き留めたうえで、新しく寄せられた意見を見逃さないよう消したということだ。

後から書き足された更新履歴

この版は大失敗で、みんなのセーブデータを壊してしまった。ひどい失敗だった。二度と起こさない。
