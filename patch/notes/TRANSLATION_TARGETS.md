# Grimoire 日本語化: 翻訳対象の総一覧

ゲーム内で画面に出る文字の出どころを、種類ごとに全部洗い出した結果。
翻訳はこの一覧のファイルを訳し、`install_test.bat <訳フォルダ>` で書庫を作り直して入れる。

## 1. テキスト表（TXT / NTX）… 本文の大部分

| 場所 | ファイル | 訳す行 | 文字数（英語） |
|---|---|---|---|
| `extracted/TXT/*.txt` | 13ファイル（MASTER、GAMETEXT、ID、SUPERID、SPELLTXT、STORY、CREDITS など） | 25,161 | 約74万 |
| `extracted/NTX/*.txt` | 64ファイル（NPCごとの会話） | 13,526 | 約41万 |

（このほか、英語のまま残す行が1,453行ある。下の「訳してはいけないもの」を参照）

### 訳してはいけないもの・形を保つもの（`tools/policy.py` で build 時に自動チェック）

- **英語のまま残す**（変えると無視され警告が出る）
  - `LOGFLAGS.TXT` 全体（開発ツール用の説明書き。画面に出ない）、`HELP.LST`（画像ファイル名）
  - `MASTER.TXT` のセクション:
    `CHEATS`（チート。逆さ綴りで入力と照合）、`PASSWORDS`（YES/NO などプレイヤーが打つ答え）、
    `CLIMBER`（climb up などの入力語）、`NPCTRIGS`（WHO/WHAT… 会話の質問語）、
    `GLOBALS` `MYSTERY` `LOGICFLAGS`（フラグ名）、`SEFX` `MIDI` `SCENES` `ANIMATIONS` `ATMOSPHERICS`
    `EFXANIMS` `LIGHTING` `UNIQUE` `NPCLOGIC` `ACTIONS` `LISTS`（内部名）、
    `FSUGGEST` `MSUGGEST`（名前入力欄に入る名前の候補）、
    `AMBIENCE` `SPELLTYPE` `IMPORT` `PERKS`（画面に出るか未確認。安全のため英語のまま、テストで確認）
- **カンマ区切りの形を保つ**（欄の数、`*` `-`、数字だけの欄を変えるとエラー）
  - `ITEMS`「名前,未鑑定の名前」、`MONSTERS`「単数,複数,未鑑定の単数,未鑑定の複数,群れ ~」、
    `MULTICHOICE`「題目,選択肢…,正解の番号列」、`OPDESC`
- **謎かけ** `LOCKHINT.TXT`「問題,答え」: 答え（最後のカンマの後ろ）はプレイヤーが入力するので英語のまま
- **文の部品として差し込まれる語**: `SEX`（Male/Himself など代名詞）、`SEVERITY`（badly など）、
  `PATHTAGS`（方角）、`LEVELS`（序数）など。差し込まれる先の文と合わせて訳すこと
- 擬似訳のツールもこの決まりに従う（以前の擬似訳ではチートが壊れていた）

- 行の書式: `番号<TAB>本文`。訳文は UTF-8 でそのまま書く
- 訳さない行: `@00001` のような見出し、`*GAMETEXT`、`[pag]`（改ページ）、`[new]`
- 文中の差し込み記号は残す: `[sub]` `[tgt]` `[itm]` `[npc]` `[tag]` `[num]` `[des]` `[act]` `[val]` `[sal]` `[gpc]`
- 書式記号も残す: `<B>` `<BC>` `<HC>` `<S>` `<H>` `<I>` `<C>`
- 1行の幅: 英文は約35文字で改行済み。日本語は全角17〜18文字前後で改行する
- 注意するセクション（`MASTER.TXT`）
  - `@CONDITIONS` と `@RESISTANCES`: 極小の一覧では英語に戻る（`tools/make_fallback.py`）。
    **先頭2文字・3文字が互いに重ならない訳語にする**（重なると警告が出る）
  - 人体図の部位名など、6または9バイト（日本語2〜3文字）で切られる短い欄がある
  - メインメニューのボタン（1400行付近 `THE STORY` など）もここ

## 2. データベース

| 場所 | 中身 | 件数 | 上限 |
|---|---|---|---|
| `extracted/DBS/GPC.DBS.txt` | 職業15種の称号（各9） | 135 | 12バイト（日本語4文字） |
| 同上 | 職業の説明 15、技能の説明 53 | 68 | 78バイト（日本語26文字） |
| `extracted/DBS/NPCWORDS.MLB.txt` | NPC共通の会話（VERBOSE / BRIEF） | 451欄（355話題） | なし |

- 行の書式: GPC は `位置:上限:詰め物<TAB>本文`、MLB は `番号.VERBOSE<TAB>本文`（改行は `\n`）
- 上限を超えると build がエラーで止まる
- MLB の `# … SYNONYMS=…` 行は参考用。**SYNONYMS はプレイヤーが入力する単語なので英語のまま**

| 画像 | 内容 |
|---|---|
| `GUI/GUI011` | 「ASSAY ITEM」（鑑定）と小見出し BAC / PRO |
| `GUI/GUI012`, `GUI013` | 「ENTER」ボタン |
| `GUI/GUI016`, `GUI017` | 「RESISTANCES」「CONDITIONS」 |
| `GUI/GUI028`, `GUI058` | 縦書きの「GPC」「NPC」 |
| `GUI/GUI051`, `GUI057`, `GUI060` | 「DELETED」「NEW」「POWER LEVEL」 |
| `GUI/GUI111` | タロットカード（FOOL〜WORLD、ACE/KING/KNIGHT/PAGE/QUEEN） |
| `MIC/MOUSE19`〜`23` | 会話カーソル「WHO」「ROW」「ITEM」「BYE」「ITEM?」 |
| `HLP/KEYCUTS`, `KEYPAD` | キーボード／テンキー操作の説明図（文字多数） |
| `SCN/SCENE17`, `18`, `70` | 広告ビラ「HAVOC SEED」「METRONOME MYSTERIUM」、手配書「HAVE YOU SEEN THIS BABY?」 |

- 訳さずに残す想定: 会社ロゴ（`SCR/INTRO`）、タイトル（`SCR/TITLE`、`SCN/SCENE16`、`GUI001` など）
- 画像形式: 9バイトのヘッダ（幅2・高さ2・0が5バイト）＋ 8ビットの点（256色、パレット `TRUERGB.PAL`、下の行から）
- 編集の元: `extracted/IMG/<種別>/<名前>.png`（上の表の21枚、パレット付きPNG）
- 差し替え方: 編集したPNGを `<訳フォルダ>/IMG/<種別>/<名前>.png` に置き、`install_test.bat <訳フォルダ>` で書庫を作り直す
  - 大きさは元と同じにすること（違うと build がエラーで止まる）
  - パレット付きPNGならそのまま、フルカラーのPNGなら変わった点だけ近い色に置き換わる（0番の透明は元の透明部分だけ）
  - 全748枚で「書き出し→書き戻し」が元と完全一致することを確認済み（`tools/imgtool.py check`）
- 見出しの描き替え: `tools/retitle.py <元png> <出力png> x0 y0 x1 y1 <日本語>`
  - 指定した範囲の文字を消し、元の文字の行ごとの色（グラデーション）で日本語を描く（右下に1pxの影）
  - 例（試作済み・ゲーム内で表示確認済み、`patch_imgtest/`）:
    `GUI016` 「耐 性」 範囲 16 16 172 30、`GUI017` 「状 態」 範囲 16 15 172 29
  - ボタン（ENTER）、タロット、会話カーソル、操作説明図、張り紙などは文字が小さく、
    範囲ごとに描き分ける必要がある（翻訳の段階で作業）
- 文字なし: アイテムのアイコン、肖像、床・壁の模様、場面画像の残り、呪文アイコンなど

## 5. 対象外（訳さない）と確認したもの

- NPC の台本 `SKP/*.CS`: 画面に出す文字列を直接持たない（`Say(番号)` でテキスト表を参照）。
  `OnSubject_XXX` の英単語は会話のキーワードなので変えない
- 呪文の台本 `SPL/*.SPL`: 先頭行の名前は見出しのみ。表示はテキスト表（SPELLTXT）を参照
- `DLG`、その他の `DBS`: 文字なし
- ウィジェット用フォントの文字見本（`GUI025`、`GUI029`）、フォントファイル（`FGF`）

## 6. 日本語表示のために DLL で直した箇所（参考）

- 描画: Fastgraph の描画2関数＋幅・高さ、ウィジェット用フォントの描画・幅（これで文字描画の経路は全部）
- 文字の掃除処理（0x4FBFC0）が日本語を空白に変えていたのを修正（職業の説明が消える原因だった）
- 極小フォントは美咲ゴシック、行間5pxの一覧は英語に戻す
- 文字列の途中で切られた日本語（UTF-8 の途中）は描かない

## 7. 翻訳後のテスト項目（まだ画面で確かめていないところ）

ゲームを進めないと出ない画面。表示の仕組みは共通なので大きな問題は起きにくいと見て、**翻訳を入れてからの通しテストで確認する**と決めた。
（チートで町へ移動して確かめようとしたが、入力の方法が特定できなかった。探索中に `WARP` と打っても発動しない。
テキスト表のデータは読み込み後に別の構造へ移され、デバッガで照合処理までたどれなかった）

各項目で見ること: 文字化け・欠け（行末の切れ）・はみ出し・英語の残り・差し込み語（`[sub]` など）の語順

- [ ] NPC との会話: キーワード入力欄で英単語が通るか、MLB の答え、NPC ごとの会話（NTX）、改ページ
- [ ] 店・自動販売機: 品名、値段の文、売買の確認
- [ ] 宝箱・鍵: 謎かけ（LOCKHINT）の問題が日本語、答えは英語で通るか
- [ ] アイテムの鑑定（GUI011 の画像も）、未鑑定の名前
- [ ] 呪文の詠唱: 呪文名・説明（SPELLTXT）・効果の文
- [ ] 戦闘中のメッセージ: 攻撃・被害・状態変化の文、モンスターの単数・複数・群れ
  （群れの名前 `Pack ~` は「群れの語 + 空白 + 複数形」とつながれ、`~` はフォント上 "of" の字形。日本語は DLL が「<名前>の群れ」に並べ替える（NOTES_ja.md 10番）。以前のメモ: 部位 `Crown ~ Asps` の例から `~` は "of" の意味の可能性あり。exe には "X of Y" を組み立てる処理（0x4F6CB5 付近）もある）
- [ ] キャラクター作成: 名前入力（候補の名前が英語で出るか）、肖像の選択
- [ ] セーブ画面、レベルアップ、全滅、エンディング
- [ ] 技能の説明（GPC.DBS）の表示場所
- [ ] 英語のまま残した `AMBIENCE` `SPELLTYPE` `IMPORT` `PERKS` が画面に出ていないか（出ていたら訳す対象へ移す）
- [ ] 会話カーソル（MOUSE19〜23）・操作説明図・張り紙の差し替え画像

## 8. 翻訳の進め方（道具）

1. **用語集** `glossary/terms.tsv`（3,073語。誤検出の候補95語以外は仮訳済み）
   - `tools/glossary.py apply extracted glossary/terms.tsv <訳フォルダ>`: アイテム・魔物・呪文・技能などの一覧と
     職業の称号を用語集から書き込む（MASTER の用語の行 2,128 行 + GPC の称号）
   - `tools/glossary.py check ...`: 本文の訳に、決めた固有名詞の訳が使われているか（段落単位で照合）
2. **本文のチャンク** `chunks/`（165チャンク、27,753項目、英語約110万字）
   - `tools/chunks.py make`: 分割。段落（`L行数 W幅` 付き）は1行で訳し、collect が原文と同じ行数に折り返す
   - `tools/chunks.py check extracted chunks <ID> [--show]`: 1チャンクの自己検査（訳漏れ、差し込み記号、
     行数オーバー、カンマ欄、用語）
   - `tools/chunks.py collect extracted chunks <訳フォルダ>`: 全チャンクの訳を訳フォルダの TXT/NTX に書き出す
   - 担当者への指示: `TRANSLATOR_BRIEF.md`、決まり: `STYLE_ja.md`
   - 試訳: `0091_NPC005`（コファーガス卿の会話）済み
3. 長い1行の文は build が見えない折り返し位置を入れ、DLL が幅0で描く（ゲームの折り返しが日本語でも働く）
4. 残り: GPC の説明（68）、MLB の答え（451欄）、`dll/ui_strings.txt` の確定、画像の描き替え
