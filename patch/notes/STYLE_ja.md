# 訳し方の決まり（文体・表記・長さ）

用語集 `glossary/terms.tsv` と本文の翻訳はこの決まりに従う。

## 1. 文体

- 地の文・ナレーション・システムの文: 常体（〜した／〜だ／〜である）。簡潔に。
  例: `[tgt] KILLED` → `[tgt]を倒した`、`The door is locked.` → `扉には鍵がかかっている。`
- NPC の台詞: その人物らしい口調（王族は尊大、商人は愛想よく、子供はくだけて、魔物は不気味に）。
  一人の NPC の口調は最後まで揃える。
- プレイヤーへの問いかけ・確認: 「〜しますか？」
- 原文の大文字だけの強調（`KILLED` など）は普通の日本語にしてよい。`!!!` などの記号はなるべく残す。
- 原文のジョーク・言葉遊び・パロディは、意味より面白さを優先して日本語で通じるように訳す。

## 2. 表記

- 固有名詞（人名・地名・神の名・組織名）はカタカナ。長音は「ー」、名前の区切りは「・」。
  例: `Junga Din` → `ジュンガ・ディン`、`Captain Krone` → `クローネ船長`（肩書は訳す）
- 意味のある名前（`The White Owl`、`Green Mandarin`、`Fertile Crescent`）は訳してよい（`白き梟`、`緑の官吏`、`肥沃な三日月地帯`）。
- 既に日本で定着している訳があればそれを使う（タロット、ギリシャ神話、一般的なファンタジーの魔物: `Werewolf` 人狼、`Lich` リッチ、`Banshee` バンシー）。
- 数字・英字は半角。日本語の文の中の句読点・感嘆符は全角（`、。！？「」`）。`...` は `……`（2つ）にする。
  カンマ区切りの欄の区切り `,` と、英語のまま残す部分の記号は半角のまま。
- 引用符付きの名前（`"LACHESIS"` など）は、用語集では中身だけを訳す。引用符はツールが元のまま付け直す。
- 英語のまま残すもの: 略語（`NAC` `HPS` など）、プレイヤーが入力する語（合言葉・謎かけの答え・会話のキーワード）。

## 3. 長さ（画面の幅）

全角1文字は英字約2文字分の幅。**訳語の幅（全角=2、半角=1）は原文の英字数以内を目安にする**。
一覧や表に並ぶ名前は特に短く。どうしても長くなる場合は 1.5 倍まで（それを超えると `glossary.py check` が警告する）。

- 称号（`title`）: **全角4文字まで**（12バイトの制限。超えると build がエラー）
- 部位名（`hitloc`）: 6/9バイトで切られる一覧があるので **全角2文字、長くても3文字**
- 状態（`condition`）・耐性（`resistance`）: 極小の一覧では先頭だけが出る。
  **同じ区分の中で先頭2文字が他と重ならない**ようにする（例: 「毒」と「毒霧」は不可）
- 地図の凡例（`legend`）: 全角2〜3文字
- 本文: 原文は約35字で改行済み。翻訳は段落ごとに1行で書けばよい。`tools/chunks.py collect` が
  原文と同じ行数・幅に自動で折り返す（句読点の後やひらがな→漢字の境目で改行、行頭禁則あり）。
  詩や箇条書きなど改行位置を決めたいときは、訳文を複数行に分けて書く
- 長い1行の文（呪文の説明 `SPELLTXT`、`@ATTDESC`、`@MENUBOOK`、NPC 共通の答え MLB など）はゲームが折り返す。
  build が日本語の文字の間に見えない折り返し位置（DLL が幅0で描く空白）を入れるので、そのまま1行で書く
- **折り返されない1行の欄**: 種族の説明 `RACEDESC.TXT` は1行が全角28文字まで（それ以上は枠の外で切れる）。
  職業の説明（GPC）は78バイト（全角26文字）まで

## 4. 用語集の区分（`cat` の欄）

| 区分 | 中身 | 区分 | 中身 |
|---|---|---|---|
| race | 種族 | spell | 呪文名 |
| vocation | 職業 | school / page | 呪文の系統・頁 |
| title | 職業ごとの称号（全角4文字まで） | monstype / subtype | 魔物の種類・属性 |
| npc | 登場人物 | itemclass / itemtype | アイテムの分類 |
| place | 地名（地方） | hoard / container | 店・宝の山・宝箱の名前 |
| patron | 守護神 | hitloc | 体の部位（全角2〜3文字） |
| party | 組織・勢力 | tarot | タロットの札 |
| name? | 本文から見つけた固有名詞の候補（訳さない語・誤検出は ja を空のまま） | legend | 地図の凡例 |
| attribute / condition / resistance / skill | 能力値・状態・耐性・技能 | item / item_unid | アイテム名・未鑑定の名前 |
| | | monster / monster_pl / monster_unid / monster_unid_pl / monster_group | 魔物（単数・複数・未鑑定・未鑑定の複数・群れ） |

- 日本語には単数・複数の区別がないので、`monster_pl` は普通 `monster` と同じ訳にする（「〜たち」は付けない）
- `monster_group` の `~` はそのまま残す（例: `Pack ~` → `~の群れ`）。DLL が描く時に「<名前>の群れ」に並べ替える。群れの語以外の訳文では `~` を使わない（ゲームのフォントでは "of" の字形になる）
- 同じ英語でも区分ごとに別の訳にしてよい（`Strength` は能力値なら「筋力」、呪文なら「剛力」、タロットなら「力」）
